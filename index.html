Comment ça marche ?

  1. Crée une room et partage le code + mot de passe à ton ami.
  2. Quand les deux joueurs sont connectés, l’hôte lance le round.
  3. Vous avez 60 secondes pour dessiner le thème affiché.
  4. À la fin, vos dessins sont révélés. L’hôte peut lancer le thème suivant.

Astuce : les touches et outils sont pensés pour souris, stylet et écran tactile.
